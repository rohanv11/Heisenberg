# GEMINI.md

## General Philosophy
- Always think before coding.
- Prefer clean Low-Level Design (LLD) over quick hacks.
- Follow SOLID principles.
- Prioritize readability and maintainability.
- Avoid premature optimization unless performance is critical.

## 🧱 Architecture & Design
- Recommend modular and loosely coupled designs.
- Use dependency injection where applicable.
- Ensure separation of concerns.
- For game dev, prioritize smooth real-time experience.

## ✅ Coding Guidelines
- Use meaningful variable/function names.
- Avoid magic numbers; use constants/enums.
- Handle edge cases proactively.

## 🧪 Testing
- Recommend testable design.
- Provide unit test examples when possible.
- Validate game logic with clear test cases.

## 💡 AI Agent Instructions
- Before generating code, ask:
  - What is the input/output expected?
  - Are there any edge cases?
- If design is unclear, suggest LLD options first.
- If a game rule is ambiguous, clarify or infer logically.
